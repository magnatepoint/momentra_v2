# Design tokens

`personal.tokens.json` is the source of truth for the Personal v1.1 theme (Personal mode only).
Together with `design/taxonomy/personal-taxonomy.v1.json` and `design/assets/personal/manifest.json`
it is generated into iOS, Android and the backend by `tools/design-pipeline`. See
[`tools/design-pipeline/README.md`](../../tools/design-pipeline/README.md). Don't edit generated files by hand.
